# Product Brief

## Product name

Lazy Lands

## One-liner

Lazy Lands is a Campaign Companion for Dungeon Masters that uses AI to preserve narrative continuity between role-playing sessions.

## Problem

Preparing a long-running D&D campaign is hard because context accumulates over time.

The issue is not a lack of ideas. The issue is remembering:

- NPCs and their current state.
- Factions and their motivations.
- Open conflicts.
- Promises made by players.
- Consequences from previous sessions.
- Secrets, social tensions and unresolved arcs.

Generic AI tools can generate an isolated one-shot or encounter, but they do not understand what happened in session 3 and how it should affect session 7.

## Solution

Lazy Lands acts as an external memory and co-writer for the DM.

The DM provides campaign context, records what happened after each session, validates relevant memories, and asks the system to prepare a coherent proposal for the next session.

## Target user

Primary user:

- Dungeon Master running a long-form tabletop RPG campaign.

Secondary users:

- DMs who prepare episodic adventures.
- DMs who want better continuity without maintaining complex notes manually.
- Story-focused players who care about consequence and narrative memory.

## Product positioning

Lazy Lands is not a generic one-shot generator.

It is a continuity engine for campaign preparation.

## Main value proposition

Any AI can generate a one-shot.

Lazy Lands remembers your campaign.

## Key product principles

### The DM is always in control

AI output is always a draft, never canon.

The DM decides what is accepted, edited, ignored or used at the table.

### Memory is explicit

The system should not silently decide what matters.

After a session, the AI proposes memory candidates. The DM accepts, edits or rejects them.

### Coherence is the product

The value is not generation itself.

The value is coherent generation based on accumulated campaign context.

### Continuity must be visible

Generated sessions should show how they connect with previous events, accepted memories, factions and open arcs.

If the DM cannot perceive continuity, the product value is lost.

## MVP success criteria

The MVP is successful if a DM can:

1. Create a campaign from free text.
2. Review extracted campaign entities.
3. Register a played session.
4. Accept relevant memory suggestions.
5. Generate a coherent next session proposal.
6. Understand why the generated proposal connects with previous campaign events.
